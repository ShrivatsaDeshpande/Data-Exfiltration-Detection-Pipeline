# Metrics

## Model performance
- Accuracy: overall proportion of correct predictions.
- Precision: proportion of predicted alerts that are truly exfiltration events.
- Recall: proportion of true exfiltration events detected by the model.
- F1-score: balanced measure of precision and recall.
- Confusion matrix: counts of true positives, false positives, true negatives, and false negatives.

## Security operations
- Open alerts over time.
- Average age of open alerts.
- Alerts reopened during the selected period.
- Resolution velocity.
- Introduced versus prevented issues over time.

## Exfiltration-focused signals
- Total outbound transfers by user.
- Total outbound transfers by destination.
- Unusual destination ports.
- Producer/consumer ratio anomalies.
- Volume spikes above baseline by user group.
