# Structure Notes

## Recommended repository layout
```text
Data-Exfiltration-Detection-Pipeline/
├── data/
├── notebooks/
├── src/
├── dashboard/
├── reports/
├── insights.md
├── metrics.md
└── dashboard_structure.md
```

## Folder purpose
- `data/`: raw logs and processed data.
- `notebooks/`: experiments and analysis.
- `src/`: preprocessing, feature engineering, training, and detection.
- `dashboard/`: visualization code and dashboard assets.
- `reports/`: exported charts and summaries.

## README note
The README should explain the pipeline clearly:
1. Ingestion.
2. Labeling.
3. Feature extraction.
4. Model training.
5. Evaluation.
6. Dashboarding.
